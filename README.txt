# GroupMate v2 — เว็บจัดการงานกลุ่มแบบใช้งานได้จริงใน Browser

เวอร์ชันนี้เพิ่มฟังก์ชันจาก Prototype เดิมให้สามารถทดลองใช้งานได้จริงโดยไม่ต้องติดตั้ง Server

## ฟังก์ชันที่เพิ่ม
1. สมัครสมาชิกและเข้าสู่ระบบได้จริง
2. ลืมรหัสผ่าน / เปลี่ยนรหัสผ่านได้
3. แก้ไขชื่อและอีเมลโปรไฟล์ได้
4. เปลี่ยนรูปโปรไฟล์ได้
5. สร้างกลุ่มใหม่ได้
6. สร้างงานและมอบหมายสมาชิกได้
7. แนบไฟล์ได้หลายไฟล์
8. ดาวน์โหลดไฟล์ที่แนบได้
9. ส่งงานและเปลี่ยนสถานะเป็น Done ได้
10. เปลี่ยนสถานะ To Do / Doing / Done และเปอร์เซ็นต์ความคืบหน้าได้
11. แสดงความคิดเห็นในงานได้ และความคิดเห็นจะถูกเก็บไว้
12. มีระบบแจ้งเตือนเมื่อสร้างงาน แนบไฟล์ แสดงความคิดเห็น หรืออัปเดตสถานะ
13. Dashboard / Kanban / รายละเอียดงาน / โปรไฟล์เชื่อมข้อมูลเดียวกัน
14. ข้อมูลบัญชี งาน กลุ่ม ความคิดเห็น และสถานะเก็บใน LocalStorage
15. ไฟล์จริงเก็บใน IndexedDB ของ Browser

## วิธีใช้งาน
1. แตกไฟล์ ZIP
2. เปิด `index.html` ด้วย Chrome หรือ Microsoft Edge
3. กด "สมัครสมาชิก"
4. สร้างบัญชีแล้วเข้าสู่ระบบ
5. ทดลองสร้างกลุ่ม / เพิ่มงาน / แนบไฟล์ / แสดงความคิดเห็น / ส่งงาน

## ข้อจำกัดสำคัญ
เวอร์ชันนี้เป็นระบบที่ใช้งานจริงแบบ Local Browser:
- ข้อมูลจะอยู่ใน Browser และเครื่องที่ใช้งาน
- ถ้าเปิดเว็บจากคอมอีกเครื่อง จะไม่เห็นบัญชีและไฟล์เดิม
- ยังไม่มีฐานข้อมูลออนไลน์สำหรับให้สมาชิกหลายคนใช้งานพร้อมกันผ่านอินเทอร์เน็ต

หากต้องการระบบ Production สำหรับส่งอาจารย์แบบหลายเครื่อง/หลายคนจริง ๆ ควรเชื่อม Backend เช่น Supabase/Firebase เพื่อจัดการ Authentication, Database และ Storage.
